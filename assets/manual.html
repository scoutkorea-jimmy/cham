1. 시작하기

관리자 페이지로 들어가기

홈페이지의 모든 관리는 관리자 페이지 한 곳에서 이루어집니다.

  1. 관리자 페이지 주소로 들어갑니다

    홈페이지 맨 아래 관리자 글씨를 누르거나, 주소창에 주소 뒤에 /admin.html 을 붙여 들어갑니다. 로그인 화면이 먼저 나옵니다.

  2. 본인 아이디와 비밀번호를 넣습니다

    사람마다 아이디가 따로 있습니다. 남의 아이디를 함께 쓰지 마세요 — 누가 처리했는지 알 수 없게 됩니다.

    처음 받은 비밀번호로 로그인하면 바로 바꾸라는 화면이 나옵니다. 받은 비밀번호는 만들어 준 사람도 알고 있기 때문입니다.

  3. 왼쪽 메뉴에서 할 일을 고릅니다

    메뉴 이름 옆 숫자는 그 항목에 쌓인 건수입니다. 권한에 따라 보이는 메뉴가 다릅니다.

한 번 로그인하면 12시간 동안 유지됩니다. 공용 컴퓨터를 쓰셨다면 자리를 뜨기 전에 왼쪽 아래 로그아웃 을 눌러 주세요.
비밀번호를 여러 번 틀리면 일정 시간 잠깁니다(틀릴수록 길어집니다). 잠기면 화면에 남은 시간이 나옵니다. 남의 비밀번호를 추측해 들어오는 것을 막기 위한 장치입니다.
비밀번호는 10자 이상이고 영문·숫자·기호 중 두 가지 이상을 섞어야 합니다. 길수록 안전합니다 — 외우기 쉬운 문장을 쓰셔도 좋습니다.

먼저 알아두실 3가지

  • 자료는 서버에 저장됩니다

    어느 컴퓨터·휴대폰에서 들어가도 같은 자료가 보입니다. 여러 사람이 나눠서 관리해도 됩니다.

  • 사람마다 계정을 씁니다

    누가 언제 처리했는지 남습니다. 직원이 그만두면 계정 관리에서 사용을 중지하세요.

  • 저장을 눌러야 반영됩니다

    글을 고친 뒤 저장하지 않고 다른 메뉴로 넘어가면 확인창이 뜹니다. 이때 취소를 누르고 저장하세요.

3. 주문 처리 · 가장 많이 쓰는 기능

주문은 왼쪽에서 오른쪽으로 흘러갑니다

모든 주문은 아래 다섯 단계를 차례로 지나갑니다. 지금 어느 단계인지만 알면 무엇을 눌러야 할지 정해집니다.

어디로 가나요판매 관리›주문 관리

주문접수 결제완료 배송준비중 배송중 배송완료

이 밖에 취소 · 반품요청 · 반품완료 · 교환요청 · 교환완료 다섯 가지 예외 상태가 있습니다.

주문 하나를 처리하는 순서

  1. 왼쪽 메뉴에서 판매 관리›주문 관리 를 누릅니다

    화면 위쪽에 전체 / 주문접수 / 결제완료 / 배송준비중 / 배송중 / 배송완료 / 취소·반품·교환 탭이 있습니다. 처리할 단계의 탭을 고르세요.

  2. 처리할 주문의 왼쪽 네모칸에 체크합니다

    여러 건을 한 번에 처리하려면 여러 개에 체크하세요. 맨 위 네모칸을 누르면 전체가 선택됩니다.

  3. 위쪽 버튼 중 하나를 누릅니다

    버튼은 세 묶음으로 나뉘어 있습니다 — 결제·배송 진행 / 취소·반품·교환 / 상태 조정. 각 버튼 위에 마우스를 올리면 설명이 나옵니다.

  4. 확인창에서 대상 건수를 확인하고 실행합니다

    “선택하신 3개의 주문 중 처리 가능한 주문은 2건입니다” 처럼 알려줍니다. 표에 나온 주문번호를 눈으로 확인한 뒤 실행하세요.

검색으로 걸러낸 상태에서 맨 위 네모칸(전체 선택)을 누르면, 화면에 보이지 않는 주문까지 함께 선택됩니다. 검색을 쓴 뒤에는 전체 선택 대신 필요한 줄만 하나씩 체크하시고, 실행 전 확인창의 대상 건수와 주문번호를 반드시 확인해 주세요.

어떤 버튼을 눌러야 하나요

상황누를 버튼하는 일 · 주의할 점
통장에 돈이 들어왔다 입금확인 주문접수 → 결제완료. 반드시 입금자명과 금액을 먼저 통장에서 확인하세요. 주문접수 상태에만 눌립니다.
상품을 싸기 시작했다 배송준비 결제완료 → 배송준비중. 이때부터는 손님이 마음대로 취소할 수 없습니다.
택배를 보냈다 발송처리 → 배송중. 배송수단과 택배사를 고르고 운송장번호를 넣습니다. 택배·소포·등기는 운송장이 없으면 실행되지 않습니다. ‘배송없음’ 을 고르면 바로 배송완료가 됩니다.
직접 갖다드렸다 · 방문 수령 강제 배송완료 운송장으로 추적할 수 없는 배송을 손으로 마감합니다. 배송중 상태에서만 눌립니다.
재고가 없어 못 보낸다 판매취소 사유를 고르고 취소합니다. 배송 전 단계에서만 가능합니다. 이미 입금된 건은 환불 계좌를 손님과 정하세요.
손님이 반품·교환을 원한다 반품 접수 교환 접수 사유와 수거 주소를 넣습니다. 배송중·배송완료 주문만 접수됩니다.
반품 물건을 받고 환불까지 끝냈다 반품 완료 교환 완료 수거·검수·환불(또는 재발송)이 모두 끝난 뒤 마감하는 버튼입니다.
실수로 상태를 잘못 눌렀다 이전 단계로 되돌리기 이전 단계로만 되돌릴 수 있습니다. 배송중 이전으로 되돌리면 운송장 정보는 지워집니다. 다시 앞으로 갈 때는 각 처리 버튼을 쓰세요.
주문 찾기

표 위 검색칸에 주문번호 · 주문자 이름 · 연락처 · 입금자명 · 상품명 중 아무거나 넣으면 즉시 걸러집니다. 손님이 전화로 주문번호를 불러줄 때 씁니다.

손님이 “제 주문 어떻게 됐나요?” 물으면

손님도 직접 확인할 수 있습니다. 제품 페이지의 비회원 주문 조회에서 주문번호 + 연락처(또는 이메일)를 넣으면 진행 상태가 나옵니다. 이 방법을 안내해 드리세요.

주문 관리 화면 맨 위의 주문 처리 안내 — 단계와 버튼 설명 (펼치기) 를 누르면, 지금 이 표와 같은 설명을 화면 안에서도 볼 수 있습니다.
4. 상품 관리

상품 올리기 · 가격과 재고 고치기

어디로 가나요판매 관리›상품 관리

새 상품 올리기

  1. 판매 관리›상품 관리 → 상품 등록

    오른쪽 위 노란 버튼입니다.

  2. 기본 정보를 채웁니다

    상품명 · 판매가는 반드시 넣어야 합니다. 할인가는 비워두면 할인 없이 표시됩니다.

  3. 상세 설명을 씁니다

    글자 크기·굵기·사진·표를 넣을 수 있는 편집기입니다. 워드 쓰듯 작성하세요.

  4. 사진을 올립니다

    대표 1장(목록에 보이는 사진), 추가 사진, 상세 사진을 따로 올립니다. 고르는 즉시 미리보기가 뜹니다.

  5. 상품정보고시를 채웁니다

    원재료 · 소비기한 · 보관방법 세 가지는 식품 판매에 법으로 필요한 항목이라, 비우면 저장되지 않습니다.

  6. 상품 등록 을 누릅니다

    저장되면 제품 목록 페이지에 바로 나타납니다.

이미 올린 상품 고치기

상품 목록에서 수정 을 누르면 등록할 때와 같은 화면이 열립니다. 고친 뒤 수정 저장 을 누르세요.

보기 를 누르면 손님에게 보이는 실제 상세 페이지가 새 창으로 열립니다. 고치기 전후를 비교할 때 쓰세요.

비슷한 상품은 복제해서 만드세요

목록의 복제(종이 두 장 모양) 를 누르면 그 상품을 본떠 새 상품이 만들어집니다. 옵션 · 상품정보고시 · 배송 안내 · 사진까지 그대로 따라옵니다. 새 식초를 하나 더 낼 때 열 몇 칸을 다시 적지 않아도 됩니다.

복제한 상품은 ‘숨김’ 상태로 만들어지고 곧바로 수정 화면이 열립니다. 이름을 아직 안 고친 상품이 손님에게 보이면 안 되기 때문입니다. 이름과 내용을 고친 뒤 판매 상태를 판매중 으로 바꾸세요.

빠르게 바꾸기

목록의 판매 상태 칸에서 판매중 · 품절 · 숨김 을 바로 바꿀 수 있습니다. 수정 화면에 들어갈 필요가 없습니다.

  • 판매중

    손님이 살 수 있습니다.

  • 품절

    목록에는 보이지만 구매 버튼이 잠깁니다.

  • 숨김

    목록에서 아예 사라집니다.

옵션 쓰기 (용량·포장 등)

옵션 사용에 체크하고 옵션명(예: 용량)을 넣은 뒤, 옵션값을 줄마다 추가합니다. 값마다 추가금액과 재고를 따로 둘 수 있습니다.

예) 300ml (소) 추가금 0원 / 500ml (대) 추가금 10,000원

관련 상품 걸기

관련 상품 선택 을 눌러 목록에서 여러 개를 고르면, 상세 페이지 맨 아래 “함께 보면 좋은” 자리에 나옵니다.

배송안내와 교환·반품·환불 안내는 각 항목 옆의 기본 템플릿 불러오기 를 누르면 표준 문구가 자동으로 채워집니다. 상품마다 다르게 쓸 일이 없으면 그대로 두세요.

주문 관리 · 지도사 신청 · 문의 내역 · 매출 정산 — 이 네 화면의 오른쪽 위에 CSV 내보내기 버튼이 있습니다. 누르면 파일이 내려받아지고, 엑셀에서 바로 열립니다(한글이 깨지지 않게 처리되어 있습니다).

파일 이름 예) 주문내역_20260726.csv · 매출_month_20260726.csv — 세무 자료를 만들거나 택배사에 명단을 넘길 때 쓰세요.

6. 지도사 신청 · 문의

신청자에게 연락하고 기록 남기기

어디로 가나요고객 관리›교육과정 관리고객 관리›신청자 관리고객 관리›문의 내역

신청·문의 처리하기

  1. 목록에서 상세 · 처리 를 누릅니다

    신청자가 쓴 내용 전체가 창으로 열립니다.

  2. 상태를 고칩니다

    신청은 신규 → 상담 → 확정 → 수료(또는 취소), 문의는 신규 → 답변완료(또는 보류)로 바꿉니다.

  3. 처리 내용을 적습니다

    “3/12 통화, 4월반 희망” 처럼 통화 결과나 답변 요지를 남기세요. 다음에 누가 보아도 상황을 알 수 있습니다.

  4. 처리 저장 을 누릅니다

    저장하면 목록의 이름 앞에 초록 점이 붙어, 처리한 건임을 한눈에 알 수 있습니다.

모집 기수 등록 · 수정 · 순서 바꾸기

고객 관리›교육과정 관리 화면 맨 위에 「모집 기수」 표가 있습니다. 여기서 넣은 기수가 지도사 과정 페이지의 일정표와 신청서의 기수 선택칸에 그대로 나옵니다.

  • 추가

    표 아래 칸을 채우고 기수 추가 를 누릅니다.

  • 수정

    행 오른쪽 연필을 누르면 그 줄이 바로 입력칸으로 바뀝니다. 고친 뒤 Enter 또는 저장, 되돌리려면 Esc 또는 취소.

  • 순서 바꾸기

    행 왼쪽 손잡이를 잡고 위아래로 끌면 순서가 바뀝니다. 여기 순서가 그대로 손님 화면의 순서입니다.

손님 화면에는 위에서부터 5개만 보입니다. 기수가 쌓여도 일정표가 길어지지 않게 하기 위해서입니다. 지금 보여 주고 싶은 기수를 표의 위쪽으로 끌어 올리세요. 가려진 기수가 있으면 손님 화면 표 아래에 그 사실이 안내됩니다.
기수 이름을 바꾸면 이미 접수된 신청서에는 옛 이름이 그대로 남습니다. 신청 인원 집계가 기수 이름으로 이어져 있어, 이름을 바꾸면 그 기수의 인원이 0명으로 보일 수 있습니다. 모집을 시작하기 전에 이름을 확정하세요.

모집 상태 네 가지

  • 모집중

    신청서 선택칸에 나옵니다.

  • 예정

    일정표에는 보이지만 신청은 받지 않습니다.

  • 상시

    원데이 수업처럼 늘 접수하는 과정입니다. 신청서에 나옵니다.

  • 마감

    일정표에 흐리게 표시되고 신청은 닫힙니다.

일정이 확정되지 않았는데 모집중으로 두면, 홈페이지에 잘못된 일정이 안내됩니다. 확정 전까지는 예정으로 두세요.
7. 소식마당 · 팝업 · 파트너

공지를 올리고 첫 화면에 알리기

어디로 가나요콘텐츠 관리›게시글 관리콘텐츠 관리›팝업 관리콘텐츠 관리›파트너 관리

공지 · 소식 올리기

글쓰기는 관리자 페이지가 아니라 소식마당 페이지에서 합니다.

  1. 소식마당으로 갑니다

    관리자의 콘텐츠 관리›게시글 관리 → 소식마당에서 글쓰기 를 누르면 새 창으로 열립니다.

  2. 글쓰기 를 누릅니다

    여기서 다시 한 번 관리자 확인을 합니다. 아이디·비밀번호를 넣으세요.

  3. 제목과 본문을 쓰고 등록합니다

    사진·표·파일 첨부를 넣을 수 있습니다.

관리자의 콘텐츠 관리›게시글 관리 화면에서는 목록 확인과 삭제만 합니다.

홈 첫 화면 팝업

손님이 홈에 들어오면 뜨는 알림창입니다. 콘텐츠 관리›팝업 관리 에서 만듭니다.

  • 제목 · 내용

    필수는 제목뿐입니다.

  • 이미지

    넣으면 팝업 위쪽에 크게 나옵니다. 자동으로 용량이 줄어듭니다.

  • 시작일 · 종료일

    비워두면 계속 나옵니다. 넣으면 그 기간에만 나옵니다.

손님이 ‘오늘 하루 보지 않기’를 누르면 그 날은 다시 뜨지 않습니다. 여러 팝업이 켜져 있으면 목록에서 위에 있는 것 하나만 나옵니다.

파트너 로고

홈 아래쪽에서 옆으로 흐르는 로고 띠입니다. 콘텐츠 관리›파트너 관리 에서 추가합니다.

  • 가로로 긴 로고

    배경이 투명한 PNG를 권합니다. 세로 높이는 자동으로 맞춰집니다.

  • 링크

    넣으면 로고를 눌렀을 때 그 사이트가 새 창으로 열립니다.

  • 기본값 복원

    처음 상태로 되돌립니다. 추가한 파트너는 사라집니다.

8. 페이지 이미지

홈페이지 사진을 바꾸고 위치를 맞추기

홈 · 소개 · 전통발효식품 · 식초 · 체험지도사 · 누룩이야기 · 제품 — 일곱 페이지의 사진 자리를 직접 갈아 끼울 수 있습니다.

어디로 가나요콘텐츠 관리›페이지 이미지

사진 바꾸기

  1. 위쪽 탭에서 페이지를 고릅니다

    홈 · 협동조합 소개 · 전통발효식품 … 순서로 있습니다.

  2. 바꾸려는 자리의 사진 올리기 를 누릅니다

    자리마다 “히어로 배경 — 장독대 전경” 처럼 어디에 쓰이는 사진인지 이름이 붙어 있습니다.

  3. 오른쪽 미리보기에서 확인합니다

    올리는 즉시 실제 페이지 모습으로 보여줍니다. 새 탭을 열 필요가 없습니다.

바꾼 사진은 곧바로 손님 화면에도 반영됩니다. 예전에는 새 사진을 올려도 한동안 옛 사진이 계속 보이는 일이 있었는데(2026년 7월 고쳤습니다), 지금은 그렇지 않습니다. 그래도 옛 사진이 보인다면 Ctrl+Shift+R(맥은 Cmd+Shift+R)로 새로고침해 보세요.

사진 위치 맞추기

넓은 사진을 좁은 자리에 넣으면 위아래나 좌우가 잘립니다. 중요한 부분이 잘리지 않도록 위치를 옮깁니다.

  1. 사진이 올라간 칸을 누릅니다

    ‘위치 조정’이라고 쓰인 칸입니다. 위쪽에 조정판이 열립니다.

  2. 사진을 끌거나 화살표를 누릅니다

    가운데 중앙 을 누르면 처음 상태로 돌아갑니다.

PC 화면과 모바일 화면의 위치는 따로 저장됩니다. 위쪽 PC 화면 / 모바일 화면 토글을 바꿔가며 각각 맞춰주세요. 모바일을 따로 맞추지 않으면 PC 설정을 그대로 씁니다.
내리기 를 누르면 올린 사진이 지워지고 원래의 기본 자리표시로 돌아갑니다. 사진 자체가 삭제되므로 필요하면 원본 파일을 따로 보관해 두세요.
올린 사진도 이 컴퓨터에만 저장됩니다. 사진을 많이 바꾸셨다면 반드시 자료 백업을 하세요.
계정 관리

직원 계정 만들기 · 권한 나누기 · 손님 회원 보기

관리자(owner)에게만 보이는 메뉴입니다. 이 화면은 탭 세 개로 나뉘어 있습니다 — 함께 일하는 분의 관리자 계정, 홈페이지에 가입한 일반 계정(손님 회원), 무엇을 할 수 있는지 정하는 권한 그룹.

어디로 가나요운영 설정›계정 관리

손님이 직접 가입한 회원 보기 — 일반 계정 탭

홈페이지 오른쪽 위 로그인 을 통해 손님이 직접 회원가입할 수 있습니다. 가입한 분들은 운영 설정›계정 관리 의 일반 계정 탭에 모입니다.

  • 회원이 좋은 점

    주문할 때 이름·연락처·주소가 자동으로 채워지고, 마이페이지에서 지난 주문 내역을 한눈에 봅니다. 주문번호를 몰라도 됩니다.

  • 가입은 선택입니다

    지금까지처럼 비회원 주문도 그대로 됩니다. 회원가입을 강요하지 않습니다.

  • 비밀번호를 잊었다는 연락이 오면

    본인 확인 후 일반 계정 탭에서 그 회원의 비밀번호를 새로 정해 주세요. 지금 비밀번호가 무엇인지는 아무도 볼 수 없습니다 — 되돌릴 수 없는 형태로 저장되기 때문입니다.

회원 명단에는 이름 · 연락처 · 주소가 들어 있습니다. 화면을 켜 둔 채 자리를 비우지 마시고, 필요한 사람에게만 관리자 계정을 만들어 주세요.

계정 만들기

  1. 운영 설정›계정 관리 로 갑니다

    표 아래에 계정 만들기 칸이 있습니다.

  2. 아이디와 이름을 넣습니다

    아이디는 영문 소문자·숫자로 3자 이상(예: staff01). 이름은 화면에 표시할 실명입니다.

  3. 권한을 고릅니다

    대부분은 직원(staff)이면 충분합니다.

  4. 처음 비밀번호를 정해 알려 줍니다

    그 사람이 첫 로그인 때 직접 바꿉니다. 알려 주신 비밀번호는 그때 없어집니다.

권한 두 가지

  • 관리자 (owner)

    모든 것을 할 수 있습니다 — 계정 관리, 사이트 설정(계좌·사업자정보), 자료 백업·복원.

  • 직원 (staff)

    일상 운영을 합니다 — 주문 처리, 신청·문의 응대, 상품, 게시글, 사진. 계정 관리와 설정은 보이지 않습니다.

그만둔 직원 처리

계정을 지우지 않고 「사용 중지」 합니다. 그러면 바로 로그인할 수 없게 되고, 그 사람이 처리한 기록은 그대로 남습니다. 다시 오시면 다시 사용 으로 되살립니다.

비밀번호를 잊은 분은 수정 에서 새 비밀번호를 넣어 주세요. 그 사람의 기존 로그인이 모두 끊기고 다음 로그인 때 본인이 다시 바꿉니다.
마지막 관리자(owner)는 권한을 내리거나 사용 중지할 수 없습니다. 아무도 못 들어가는 상황을 막기 위한 장치입니다. 관리자를 바꾸실 때는 새 관리자를 먼저 만든 뒤 기존 계정을 정리하세요.
9. 설정

계좌 · 전화 · 주소 · 약도 고치기

여기서 한 번만 고치면 홈페이지 전체가 함께 바뀝니다. 페이지마다 따로 고칠 필요가 없습니다.

어디로 가나요운영 설정›설정운영 설정›검색 노출

고치는 항목어디에 반영되나
입금 계좌 · 예금주주문할 때 손님에게 보이는 무통장입금 안내와 주문 완료 화면
대표 전화 · 보조 전화전 페이지 맨 아래(푸터), 휴대폰 메뉴의 전화 걸기 버튼, 문의 페이지
이메일 · 주소 · 운영 시간전 페이지 푸터, 문의 페이지, 협동조합 소개 페이지
법인명 · 대표자 · 설립일
사업자등록번호 · 통신판매업 신고번호
업태·종목 · 교육 인증 · 제품 시험검사		전 페이지 푸터의 사업자 정보, 협동조합 소개의 ‘공식 등록 사항’ 표
약도 위치(위도·경도)협동조합 소개와 문의 페이지의 오시는 길 지도 핀

약도 핀 옮기기

  1. 주소를 먼저 넣습니다

    위쪽 주소 칸을 채웁니다.

  2. 위 주소로 찾기 를 누릅니다

    지도가 그 주소 근처로 이동합니다.

  3. 지도에서 핀을 끌어 정확히 맞춥니다

    지도를 누르기만 해도 핀이 그 자리로 옮겨갑니다. 위도·경도 숫자는 자동으로 채워집니다.

계좌는 반드시 실제 계좌로

처음에는 ‘농협 000-0000-0000-00’ 같은 예시 계좌번호가 들어 있습니다. 이대로 두면 손님이 엉뚱한 곳에 입금하게 됩니다.

홈페이지를 정식으로 여시기 전에 반드시 실제 계좌번호로 바꿔주세요. 계좌를 바꾸지 않으면 주문 안내에 예시 번호가 그대로 나갑니다.
설정을 저장한 뒤에는 손님 화면(공개 페이지)을 새로고침해야 바뀐 내용이 보입니다. 이미 열려 있던 창은 자동으로 바뀌지 않습니다.

검색에 잘 나오게 하기

운영 설정 > 운영 설정›검색 노출 에서 합니다. 한 번만 해 두면 됩니다.

구글 · 네이버에 사이트 등록하기

  1. 구글은 search.google.com/search-console 에 접속합니다

    속성 추가 → HTML 태그 방식을 고르면 meta 태그가 하나 나옵니다.

  2. 그 태그를 통째로 복사해 구글 서치콘솔 인증 코드 칸에 붙여넣습니다

    태그 전체를 붙여넣어도 됩니다. 필요한 코드만 알아서 골라 씁니다.

  3. 검색 노출 저장 을 누른 뒤, 구글 화면에서 확인을 누릅니다

    네이버는 searchadvisor.naver.com 에서 같은 방법으로 합니다.

  4. 등록이 끝나면 사이트맵 주소를 제출합니다

    주소는 이 화면 아래 검색엔진에 알리기 표에 적혀 있습니다. 새 글과 상품을 더 빨리 찾아갑니다.

링크를 보낼 때 뜨는 그림

카카오톡·문자·페이스북으로 홈페이지 주소를 보내면 그림과 제목이 함께 뜹니다. 그 그림을 그림 주소 칸에서 정합니다.

  • 가로로 긴 그림이 좋습니다

    1200 × 630 정도가 가장 잘 나옵니다. 로고처럼 정사각형이면 양옆이 잘릴 수 있습니다.

  • 오른쪽 미리보기로 확인하세요

    주소가 틀리면 미리보기 자리가 빨갛게 바뀝니다.

카카오톡은 한 번 본 그림을 한동안 기억합니다. 바꿔도 바로 안 바뀌면 하루쯤 뒤에 다시 보내 보세요.
제대로 들어갔는지 보려면, 손님 화면에서 마우스 오른쪽 → 페이지 소스 보기를 누르고 og:image 를 찾아보세요. 보이면 검색엔진도 같은 것을 봅니다.
10. 자료 백업 · 가장 중요합니다

한 달에 한 번, 자료를 내려받아 보관하세요

주문·신청·문의·상품·게시글·사진은 이제 서버에 저장됩니다. 컴퓨터를 바꿔도 사라지지 않습니다. 그래도 백업은 필요합니다 — 서버가 지켜 주지 못하는 것이 있기 때문입니다.

어디로 가나요시스템›데이터 백업

실수로 지웠을 때

서버는 지우라는 대로 지웁니다. 되돌리려면 백업이 있어야 합니다.

잘못 덮어썼을 때

가격표나 게시글을 잘못 고쳐 저장한 경우입니다.

서비스를 옮길 때

다른 업체로 옮기거나 계약이 끝날 때, 내 자료를 손에 쥐고 있어야 합니다.

백업하기 (내보내기)

  1. 시스템›데이터 백업 메뉴로 갑니다

    왼쪽 메뉴 맨 아래에 있습니다.

  2. 백업 파일 내려받기 를 누릅니다

    모든 자료와 사진이 파일 하나로 내려받아집니다.

  3. 안전한 곳에 보관합니다

    파일 이름 예) kach-backup-20260726-1204.json — USB나 클라우드(구글 드라이브·네이버 마이박스 등)에 옮겨두세요.

    사진까지 함께 담기므로 파일이 큽니다(수 MB~수십 MB).

되살리기 (가져오기)

  1. 백업 파일 선택 을 누릅니다

    보관해 둔 백업 파일을 고릅니다.

  2. 확인창에서 예를 누릅니다

    불러오기가 끝나면 페이지가 저절로 새로고침됩니다.

되살리기를 하면 지금 컴퓨터에 있는 자료가 모두 지워지고 백업 내용으로 바뀝니다. 되돌릴 수 없으니, 되살리기 전에 지금 자료도 한 번 내려받아 두세요.

권장 백업 주기

주문이 있는 달은 매주 금요일,
주문이 없는 달은 매월 1일 — 이렇게 정해두고 하시길 권합니다.

사진을 여러 장 바꾸셨거나 상품을 새로 올리신 날에는 그날 바로 한 번 더 받아두세요.

11. 이럴 땐 이렇게

자주 있는 상황과 해결 방법

이런 일이 생겼다면이렇게 하세요
주문·상품이 하나도 안 보여요 인터넷 연결을 확인하고 새로고침하세요. 자료는 서버에 있으므로 컴퓨터를 바꿔서 생긴 문제는 아닙니다. 계속 비어 있으면 담당자에게 알려 주세요.
「○○님이 먼저 저장했습니다」가 떴어요 같은 목록을 다른 사람이 동시에 고치고 있습니다. 그대로 저장하면 그분이 한 일이 사라지므로 막은 것입니다. 화면이 저절로 최신 내용으로 바뀌니, 내가 하려던 것을 다시 한 번 하고 저장하세요. 자주 뜨면 누가 어느 부분을 맡을지 미리 나눠 두시는 편이 좋습니다.
「지난 자료가 ○○건 더 있습니다」가 보여요 주문·신청·문의는 최근 1년치만 먼저 불러옵니다. 화면이 빨리 뜨게 하기 위해서입니다. 자료가 없어진 것이 아닙니다. 그 이전 것을 보시려면 표 아래 지난 자료까지 불러오기를 누르세요. 한 번 누르면 그 화면에서는 계속 전부 보입니다(새로고침하면 다시 1년치로 돌아갑니다).
목록이 30개까지만 보여요 정상입니다. 한 번에 30개씩 나누어 보여 줍니다. 표 아래쪽 1 · 2 · 3 … 또는 다음 › 을 눌러 넘기세요. 찾는 것이 있으면 검색칸을 쓰세요 — 지금 보이는 쪽뿐 아니라 전체에서 찾아 줍니다.
로그인 화면으로 자꾸 돌아가요 로그인이 12시간 지나 끊긴 것입니다. 다시 로그인하시면 됩니다. 방금 로그인했는데도 그렇다면, 다른 곳에서 비밀번호가 재설정되었을 수 있습니다(그때 모든 로그인이 끊깁니다).
고친 내용이 홈페이지에 안 보여요 손님 화면(공개 페이지)을 새로고침하세요. 키보드 F5 또는 Ctrl(⌘) + R 입니다. 그래도 안 보이면 Ctrl(⌘) + Shift + R 로 강력 새로고침을 하세요.
사진이 안 올라가요 사진 한 장은 5MB 이하여야 하고, 이미지 파일(JPG·PNG·WEBP)만 됩니다. 휴대폰으로 찍은 원본이 크면 카카오톡으로 자신에게 보내 받은 사진을 쓰시면 크기가 줄어듭니다.
로그인이 안 되고 잠겼어요 비밀번호를 여러 번 틀리면 잠깁니다. 화면에 남은 시간이 나오니 그만큼 기다렸다 다시 시도하세요. 비밀번호가 기억나지 않으면 관리자(owner)에게 재설정을 요청하세요.
잘못된 상태로 처리해 버렸어요 주문 관리의 이전 단계로 되돌리기 를 쓰세요. 이전 단계로만 되돌아갑니다. 앞으로 다시 진행할 때는 각 처리 버튼을 쓰시면 됩니다.
실수로 지웠어요 삭제한 자료는 되살릴 수 없습니다. 최근 백업 파일이 있다면 되살리기로 그 시점으로 돌아갈 수 있습니다(그 이후에 들어온 주문은 사라집니다). 그래서 백업 주기를 지키는 것이 중요합니다.
직원이 그만뒀어요 계정 관리 → 사용 중지를 누르세요. 바로 로그인할 수 없게 됩니다. 계정을 지우지 않으므로 그 사람이 처리한 기록은 남습니다.
지도가 안 나와요 인터넷 연결을 확인하세요. 지도는 외부 서비스를 씁니다. 지도가 안 나올 때도 주소 글씨는 그대로 표시되므로 손님이 위치를 확인하는 데 문제는 없습니다.
상세 설명 편집기가 안 열려요 인터넷 연결을 확인하고 페이지를 새로고침하세요. 편집기도 외부에서 불러옵니다.
글자가 너무 작아요 키보드 Ctrl(⌘) 와 + 를 함께 누르면 화면이 커집니다. Ctrl(⌘) 와 − 는 작아지고, Ctrl(⌘) 와 0 은 원래대로 돌아갑니다.
12. 정식 개설 전 점검

손님에게 열기 전에 확인할 것

아래 항목이 모두 끝나야 실제 주문을 받을 수 있습니다.

운영자가 직접 하실 일

  • 관리자 비밀번호 바꾸기 — 가장 급합니다왼쪽 아래 비밀번호 변경. 지금은 처음 정한 값 그대로라, 주소를 아는 사람이 들어와 주문자 이름·연락처·주소를 볼 수 있습니다. 회원가입을 열어 개인정보가 쌓이기 시작했으므로 오늘 바꾸세요.
  • 실제 입금 계좌 넣기운영 설정›설정 → 무통장입금 계좌. 지금은 예시 번호라 손님이 엉뚱한 곳에 입금합니다.
  • 사업자 정보 확인운영 설정›설정 → 사업자 정보. 등록번호·신고번호가 맞는지 확인하세요.
  • 샘플 자료 지우기완료 — 예시 공지·주문·신청·문의를 지웠고, 코드에서도 없앴습니다. 이제 들어오는 것이 실제 자료입니다.
  • 실제 상품 가격·재고 넣기상품 관리에서 판매가와 재고를 실제 값으로 맞추세요.
  • 직원 계정 만들기함께 일하는 분께 각자 계정을 만들어 주세요. 아이디를 같이 쓰지 않습니다.
  • 첫 백업 받아두기모든 준비가 끝난 상태를 한 번 저장해 두세요.

담당자(개발)와 함께 할 일

  • 관리자 로그인을 서버 방식으로 바꾸기완료 — 계정별 로그인, 권한 구분, 실패 시 잠금.
  • 자료를 서버에 저장하도록 바꾸기완료 — 주문·상품·게시글은 데이터베이스에, 사진은 파일 저장소에 있습니다.
  • Cloudflare 에 실제로 올리기완료 — 손님이 볼 수 있는 상태입니다.
  • 도메인 연결완료 — charmjt.org 로 열립니다(www 도 같이). 검색 설정 파일의 주소는 자동으로 맞춰지므로 따로 고칠 것이 없습니다.
  • 회원가입 열기완료 — 손님이 직접 가입해 주문 내역을 봅니다. 가입은 선택이고 비회원 주문도 그대로 됩니다.
  • 이용약관·개인정보처리방침 법무 검토회원 수집 항목을 반영해 문구를 고쳤지만(2026년 7월), 아직 초안입니다. 시행 전 검토가 필요합니다.
  • 회원 비밀번호 찾기 자동화지금은 전화로 본인 확인 후 관리자가 다시 정해 줍니다. 메일로 자동 처리하려면 발송 수단을 정해야 합니다.
