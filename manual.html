1. 시작하기

관리자 페이지로 들어가기

홈페이지의 모든 관리는 관리자 페이지 한 곳에서 이루어집니다.

  1. 관리자 페이지 주소로 들어갑니다

    홈페이지 맨 아래 관리자 글씨를 누르거나, 주소창에 주소 뒤에 /admin.html 을 붙여 들어갑니다.

  2. 아이디와 비밀번호를 넣습니다

    담당자에게 전달받은 아이디·비밀번호를 입력하고 로그인 을 누릅니다.

  3. 왼쪽 메뉴에서 할 일을 고릅니다

    왼쪽에 14개 메뉴가 세로로 있습니다. 메뉴 이름 옆 숫자는 그 항목에 쌓인 건수입니다.

새로고침하면 다시 로그인해야 합니다. 불편해 보이지만, 자리를 비운 사이 다른 사람이 관리자 화면을 열어보지 못하게 하는 안전장치입니다. 로그인 정보는 어디에도 저장되지 않습니다.
비밀번호를 5번 틀리면 5분 동안 잠깁니다. 잠기면 화면에 남은 시간이 표시됩니다. 그 시간이 지나면 다시 시도할 수 있습니다.

먼저 알아두실 3가지

  • 자료는 이 컴퓨터에 저장됩니다

    다른 컴퓨터나 휴대폰에서 관리자 페이지를 열면 주문·상품이 보이지 않습니다. 늘 같은 컴퓨터·같은 브라우저로 관리하세요.

  • 백업이 가장 중요합니다

    컴퓨터를 바꾸거나 인터넷 기록을 지우면 자료가 사라집니다. 자료 백업을 꼭 읽어주세요.

  • 저장을 눌러야 반영됩니다

    글을 고친 뒤 저장하지 않고 다른 메뉴로 넘어가면 확인창이 뜹니다. 이때 취소를 누르고 저장하세요.

3. 주문 처리 · 가장 많이 쓰는 기능

주문은 왼쪽에서 오른쪽으로 흘러갑니다

모든 주문은 아래 다섯 단계를 차례로 지나갑니다. 지금 어느 단계인지만 알면 무엇을 눌러야 할지 정해집니다.

주문접수 결제완료 배송준비중 배송중 배송완료

이 밖에 취소 · 반품요청 · 반품완료 · 교환요청 · 교환완료 다섯 가지 예외 상태가 있습니다.

주문 하나를 처리하는 순서

  1. 왼쪽 메뉴에서 주문 관리 를 누릅니다

    화면 위쪽에 전체 / 주문접수 / 결제완료 / 배송준비중 / 배송중 / 배송완료 / 취소·반품·교환 탭이 있습니다. 처리할 단계의 탭을 고르세요.

  2. 처리할 주문의 왼쪽 네모칸에 체크합니다

    여러 건을 한 번에 처리하려면 여러 개에 체크하세요. 맨 위 네모칸을 누르면 전체가 선택됩니다.

  3. 위쪽 버튼 중 하나를 누릅니다

    버튼은 세 묶음으로 나뉘어 있습니다 — 결제·배송 진행 / 취소·반품·교환 / 상태 조정. 각 버튼 위에 마우스를 올리면 설명이 나옵니다.

  4. 확인창에서 대상 건수를 확인하고 실행합니다

    “선택하신 3개의 주문 중 처리 가능한 주문은 2건입니다” 처럼 알려줍니다. 표에 나온 주문번호를 눈으로 확인한 뒤 실행하세요.

검색으로 걸러낸 상태에서 맨 위 네모칸(전체 선택)을 누르면, 화면에 보이지 않는 주문까지 함께 선택됩니다. 검색을 쓴 뒤에는 전체 선택 대신 필요한 줄만 하나씩 체크하시고, 실행 전 확인창의 대상 건수와 주문번호를 반드시 확인해 주세요.

어떤 버튼을 눌러야 하나요

상황누를 버튼하는 일 · 주의할 점
통장에 돈이 들어왔다 입금확인 주문접수 → 결제완료. 반드시 입금자명과 금액을 먼저 통장에서 확인하세요. 주문접수 상태에만 눌립니다.
상품을 싸기 시작했다 배송준비 결제완료 → 배송준비중. 이때부터는 손님이 마음대로 취소할 수 없습니다.
택배를 보냈다 발송처리 → 배송중. 배송수단과 택배사를 고르고 운송장번호를 넣습니다. 택배·소포·등기는 운송장이 없으면 실행되지 않습니다. ‘배송없음’ 을 고르면 바로 배송완료가 됩니다.
직접 갖다드렸다 · 방문 수령 강제 배송완료 운송장으로 추적할 수 없는 배송을 손으로 마감합니다. 배송중 상태에서만 눌립니다.
재고가 없어 못 보낸다 판매취소 사유를 고르고 취소합니다. 배송 전 단계에서만 가능합니다. 이미 입금된 건은 환불 계좌를 손님과 정하세요.
손님이 반품·교환을 원한다 반품 접수 교환 접수 사유와 수거 주소를 넣습니다. 배송중·배송완료 주문만 접수됩니다.
반품 물건을 받고 환불까지 끝냈다 반품 완료 교환 완료 수거·검수·환불(또는 재발송)이 모두 끝난 뒤 마감하는 버튼입니다.
실수로 상태를 잘못 눌렀다 이전 단계로 되돌리기 이전 단계로만 되돌릴 수 있습니다. 배송중 이전으로 되돌리면 운송장 정보는 지워집니다. 다시 앞으로 갈 때는 각 처리 버튼을 쓰세요.
주문 찾기

표 위 검색칸에 주문번호 · 주문자 이름 · 연락처 · 입금자명 · 상품명 중 아무거나 넣으면 즉시 걸러집니다. 손님이 전화로 주문번호를 불러줄 때 씁니다.

손님이 “제 주문 어떻게 됐나요?” 물으면

손님도 직접 확인할 수 있습니다. 제품 페이지의 비회원 주문 조회에서 주문번호 + 연락처(또는 이메일)를 넣으면 진행 상태가 나옵니다. 이 방법을 안내해 드리세요.

주문 관리 화면 맨 위의 주문 처리 안내 — 단계와 버튼 설명 (펼치기) 를 누르면, 지금 이 표와 같은 설명을 화면 안에서도 볼 수 있습니다.
4. 상품 관리

상품 올리기 · 가격과 재고 고치기

새 상품 올리기

  1. 상품 관리 → 상품 등록

    오른쪽 위 노란 버튼입니다.

  2. 기본 정보를 채웁니다

    상품명 · 판매가는 반드시 넣어야 합니다. 할인가는 비워두면 할인 없이 표시됩니다.

  3. 상세 설명을 씁니다

    글자 크기·굵기·사진·표를 넣을 수 있는 편집기입니다. 워드 쓰듯 작성하세요.

  4. 사진을 올립니다

    대표 1장(목록에 보이는 사진), 추가 사진, 상세 사진을 따로 올립니다. 고르는 즉시 미리보기가 뜹니다.

  5. 상품정보고시를 채웁니다

    원재료 · 소비기한 · 보관방법 세 가지는 식품 판매에 법으로 필요한 항목이라, 비우면 저장되지 않습니다.

  6. 상품 등록 을 누릅니다

    저장되면 제품 목록 페이지에 바로 나타납니다.

이미 올린 상품 고치기

상품 목록에서 수정 을 누르면 등록할 때와 같은 화면이 열립니다. 고친 뒤 수정 저장 을 누르세요.

보기 를 누르면 손님에게 보이는 실제 상세 페이지가 새 창으로 열립니다. 고치기 전후를 비교할 때 쓰세요.

빠르게 바꾸기

목록의 판매 상태 칸에서 판매중 · 품절 · 숨김 을 바로 바꿀 수 있습니다. 수정 화면에 들어갈 필요가 없습니다.

  • 판매중

    손님이 살 수 있습니다.

  • 품절

    목록에는 보이지만 구매 버튼이 잠깁니다.

  • 숨김

    목록에서 아예 사라집니다.

옵션 쓰기 (용량·포장 등)

옵션 사용에 체크하고 옵션명(예: 용량)을 넣은 뒤, 옵션값을 줄마다 추가합니다. 값마다 추가금액과 재고를 따로 둘 수 있습니다.

예) 300ml (소) 추가금 0원 / 500ml (대) 추가금 10,000원

관련 상품 걸기

관련 상품 선택 을 눌러 목록에서 여러 개를 고르면, 상세 페이지 맨 아래 “함께 보면 좋은” 자리에 나옵니다.

배송안내와 교환·반품·환불 안내는 각 항목 옆의 기본 템플릿 불러오기 를 누르면 표준 문구가 자동으로 채워집니다. 상품마다 다르게 쓸 일이 없으면 그대로 두세요.

6. 지도사 신청 · 문의

신청자에게 연락하고 기록 남기기

신청·문의 처리하기

  1. 목록에서 상세 · 처리 를 누릅니다

    신청자가 쓴 내용 전체가 창으로 열립니다.

  2. 상태를 고칩니다

    신청은 신규 → 상담 → 확정 → 수료(또는 취소), 문의는 신규 → 답변완료(또는 보류)로 바꿉니다.

  3. 처리 내용을 적습니다

    “3/12 통화, 4월반 희망” 처럼 통화 결과나 답변 요지를 남기세요. 다음에 누가 보아도 상황을 알 수 있습니다.

  4. 처리 저장 을 누릅니다

    저장하면 목록의 이름 앞에 초록 점이 붙어, 처리한 건임을 한눈에 알 수 있습니다.

모집 기수 등록하기

지도사 신청 화면 맨 위에 「모집 기수 관리」 표가 있습니다. 여기서 넣은 기수가 지도사 과정 페이지의 일정표와 신청서의 기수 선택칸에 그대로 나옵니다.

모집 상태 네 가지

  • 모집중

    신청서 선택칸에 나옵니다.

  • 예정

    일정표에는 보이지만 신청은 받지 않습니다.

  • 상시

    원데이 수업처럼 늘 접수하는 과정입니다. 신청서에 나옵니다.

  • 마감

    일정표에 흐리게 표시되고 신청은 닫힙니다.

일정이 확정되지 않았는데 모집중으로 두면, 홈페이지에 잘못된 일정이 안내됩니다. 확정 전까지는 예정으로 두세요.
7. 소식마당 · 팝업 · 파트너

공지를 올리고 첫 화면에 알리기

공지 · 소식 올리기

글쓰기는 관리자 페이지가 아니라 소식마당 페이지에서 합니다.

  1. 소식마당으로 갑니다

    관리자의 게시글 관리 → 소식마당에서 글쓰기 를 누르면 새 창으로 열립니다.

  2. 글쓰기 를 누릅니다

    여기서 다시 한 번 관리자 확인을 합니다. 아이디·비밀번호를 넣으세요.

  3. 제목과 본문을 쓰고 등록합니다

    사진·표·파일 첨부를 넣을 수 있습니다.

관리자의 게시글 관리 화면에서는 목록 확인과 삭제만 합니다.

홈 첫 화면 팝업

손님이 홈에 들어오면 뜨는 알림창입니다. 팝업 관리 에서 만듭니다.

  • 제목 · 내용

    필수는 제목뿐입니다.

  • 이미지

    넣으면 팝업 위쪽에 크게 나옵니다. 자동으로 용량이 줄어듭니다.

  • 시작일 · 종료일

    비워두면 계속 나옵니다. 넣으면 그 기간에만 나옵니다.

손님이 ‘오늘 하루 보지 않기’를 누르면 그 날은 다시 뜨지 않습니다. 여러 팝업이 켜져 있으면 목록에서 위에 있는 것 하나만 나옵니다.

파트너 로고

홈 아래쪽에서 옆으로 흐르는 로고 띠입니다. 파트너 관리 에서 추가합니다.

  • 가로로 긴 로고

    배경이 투명한 PNG를 권합니다. 세로 높이는 자동으로 맞춰집니다.

  • 링크

    넣으면 로고를 눌렀을 때 그 사이트가 새 창으로 열립니다.

  • 기본값 복원

    처음 상태로 되돌립니다. 추가한 파트너는 사라집니다.

8. 페이지 이미지

홈페이지 사진을 바꾸고 위치를 맞추기

홈 · 소개 · 전통발효식품 · 식초 · 체험지도사 · 누룩이야기 · 제품 — 일곱 페이지의 사진 자리를 직접 갈아 끼울 수 있습니다.

사진 바꾸기

  1. 위쪽 탭에서 페이지를 고릅니다

    홈 · 협동조합 소개 · 전통발효식품 … 순서로 있습니다.

  2. 바꾸려는 자리의 사진 올리기 를 누릅니다

    자리마다 “히어로 배경 — 장독대 전경” 처럼 어디에 쓰이는 사진인지 이름이 붙어 있습니다.

  3. 오른쪽 미리보기에서 확인합니다

    올리는 즉시 실제 페이지 모습으로 보여줍니다. 새 탭을 열 필요가 없습니다.

사진 위치 맞추기

넓은 사진을 좁은 자리에 넣으면 위아래나 좌우가 잘립니다. 중요한 부분이 잘리지 않도록 위치를 옮깁니다.

  1. 사진이 올라간 칸을 누릅니다

    ‘위치 조정’이라고 쓰인 칸입니다. 위쪽에 조정판이 열립니다.

  2. 사진을 끌거나 화살표를 누릅니다

    가운데 중앙 을 누르면 처음 상태로 돌아갑니다.

PC 화면과 모바일 화면의 위치는 따로 저장됩니다. 위쪽 PC 화면 / 모바일 화면 토글을 바꿔가며 각각 맞춰주세요. 모바일을 따로 맞추지 않으면 PC 설정을 그대로 씁니다.
내리기 를 누르면 올린 사진이 지워지고 원래의 기본 자리표시로 돌아갑니다. 사진 자체가 삭제되므로 필요하면 원본 파일을 따로 보관해 두세요.
올린 사진도 이 컴퓨터에만 저장됩니다. 사진을 많이 바꾸셨다면 반드시 자료 백업을 하세요.
9. 설정

계좌 · 전화 · 주소 · 약도 고치기

여기서 한 번만 고치면 홈페이지 전체가 함께 바뀝니다. 페이지마다 따로 고칠 필요가 없습니다.

고치는 항목어디에 반영되나
입금 계좌 · 예금주주문할 때 손님에게 보이는 무통장입금 안내와 주문 완료 화면
대표 전화 · 보조 전화전 페이지 맨 아래(푸터), 휴대폰 메뉴의 전화 걸기 버튼, 문의 페이지
이메일 · 주소 · 운영 시간전 페이지 푸터, 문의 페이지, 협동조합 소개 페이지
법인명 · 대표자 · 설립일
사업자등록번호 · 통신판매업 신고번호
업태·종목 · 교육 인증 · 제품 시험검사		전 페이지 푸터의 사업자 정보, 협동조합 소개의 ‘공식 등록 사항’ 표
약도 위치(위도·경도)협동조합 소개와 문의 페이지의 오시는 길 지도 핀

약도 핀 옮기기

  1. 주소를 먼저 넣습니다

    위쪽 주소 칸을 채웁니다.

  2. 위 주소로 찾기 를 누릅니다

    지도가 그 주소 근처로 이동합니다.

  3. 지도에서 핀을 끌어 정확히 맞춥니다

    지도를 누르기만 해도 핀이 그 자리로 옮겨갑니다. 위도·경도 숫자는 자동으로 채워집니다.

계좌는 반드시 실제 계좌로

처음에는 ‘농협 000-0000-0000-00’ 같은 예시 계좌번호가 들어 있습니다. 이대로 두면 손님이 엉뚱한 곳에 입금하게 됩니다.

홈페이지를 정식으로 여시기 전에 반드시 실제 계좌번호로 바꿔주세요. 계좌를 바꾸지 않으면 주문 안내에 예시 번호가 그대로 나갑니다.
설정을 저장한 뒤에는 손님 화면(공개 페이지)을 새로고침해야 바뀐 내용이 보입니다. 이미 열려 있던 창은 자동으로 바뀌지 않습니다.
10. 자료 백업 · 가장 중요합니다

한 달에 한 번, 자료를 내려받아 보관하세요

주문·신청·문의·상품·게시글·사진 — 모든 자료는 지금 쓰고 계신 이 컴퓨터의 브라우저 안에 저장됩니다. 서버에 올라가 있지 않기 때문에, 아래 상황에서 되돌릴 수 없이 사라집니다.

컴퓨터를 바꿨을 때

새 컴퓨터에는 자료가 없습니다.

인터넷 기록을 지웠을 때

‘쿠키·사이트 데이터 삭제’를 하면 함께 지워집니다.

다른 브라우저로 열었을 때

크롬에서 만든 자료는 엣지에서 보이지 않습니다.

백업하기 (내보내기)

  1. 데이터 백업 메뉴로 갑니다

    왼쪽 메뉴 맨 아래에 있습니다.

  2. 백업 파일 내려받기 를 누릅니다

    모든 자료와 사진이 파일 하나로 내려받아집니다.

  3. 안전한 곳에 보관합니다

    파일 이름 예) kach-backup-20260726-1204.json — USB나 클라우드(구글 드라이브·네이버 마이박스 등)에 옮겨두세요.

되살리기 (가져오기)

  1. 백업 파일 선택 을 누릅니다

    보관해 둔 백업 파일을 고릅니다.

  2. 확인창에서 예를 누릅니다

    불러오기가 끝나면 페이지가 저절로 새로고침됩니다.

되살리기를 하면 지금 컴퓨터에 있는 자료가 모두 지워지고 백업 내용으로 바뀝니다. 되돌릴 수 없으니, 되살리기 전에 지금 자료도 한 번 내려받아 두세요.

권장 백업 주기

주문이 있는 달은 매주 금요일,
주문이 없는 달은 매월 1일 — 이렇게 정해두고 하시길 권합니다.

사진을 여러 장 바꾸셨거나 상품을 새로 올리신 날에는 그날 바로 한 번 더 받아두세요.

11. 이럴 땐 이렇게

자주 있는 상황과 해결 방법

이런 일이 생겼다면이렇게 하세요
주문·상품이 하나도 안 보여요 다른 컴퓨터나 다른 브라우저로 여신 것은 아닌지 먼저 확인하세요. 늘 쓰던 컴퓨터가 맞다면, 인터넷 기록이 지워졌을 수 있습니다. 데이터 백업 → 백업 파일 선택으로 되살리세요.
고친 내용이 홈페이지에 안 보여요 손님 화면(공개 페이지)을 새로고침하세요. 키보드 F5 또는 Ctrl(⌘) + R 입니다. 그래도 안 보이면 Ctrl(⌘) + Shift + R 로 강력 새로고침을 하세요.
“저장 공간이 부족합니다” 라고 나와요 브라우저에 저장할 수 있는 양을 넘었습니다. 먼저 백업을 받아 보관한 뒤, 오래된 게시글이나 쓰지 않는 상품 사진을 정리하세요. 사진은 되도록 한 장에 2MB 이하로 올리시길 권합니다.
로그인이 안 되고 잠겼어요 비밀번호를 5번 틀리면 5분간 잠깁니다. 화면에 남은 시간이 나옵니다. 5분 뒤에 다시 시도하세요.
잘못된 상태로 처리해 버렸어요 주문 관리의 이전 단계로 되돌리기 를 쓰세요. 이전 단계로만 되돌아갑니다. 앞으로 다시 진행할 때는 각 처리 버튼을 쓰시면 됩니다.
실수로 지웠어요 삭제한 자료는 되살릴 수 없습니다. 최근 백업 파일이 있다면 되살리기로 그 시점으로 돌아갈 수 있습니다(그 이후에 들어온 주문은 사라집니다).
지도가 안 나와요 인터넷 연결을 확인하세요. 지도는 외부 서비스를 씁니다. 지도가 안 나올 때도 주소 글씨는 그대로 표시되므로 손님이 위치를 확인하는 데 문제는 없습니다.
상세 설명 편집기가 안 열려요 인터넷 연결을 확인하고 페이지를 새로고침하세요. 편집기도 외부에서 불러옵니다.
글자가 너무 작아요 키보드 Ctrl(⌘) 와 + 를 함께 누르면 화면이 커집니다. Ctrl(⌘) 와 − 는 작아지고, Ctrl(⌘) 와 0 은 원래대로 돌아갑니다.
12. 정식 개설 전 점검

손님에게 열기 전에 확인할 것

아래 항목이 모두 끝나야 실제 주문을 받을 수 있습니다.

운영자가 직접 하실 일

  • 실제 입금 계좌 넣기설정 → 무통장입금 계좌. 지금은 예시 번호입니다.
  • 사업자 정보 확인설정 → 사업자 정보. 등록번호·신고번호가 맞는지 확인하세요.
  • 샘플 자료 지우기‘샘플’ 표시가 붙은 게시글과 시험용 주문·신청을 삭제하세요.
  • 실제 상품 가격·재고 넣기상품 관리에서 판매가와 재고를 실제 값으로 맞추세요.
  • 첫 백업 받아두기모든 준비가 끝난 상태를 한 번 저장해 두세요.

담당자(개발)와 함께 할 일

  • 관리자 로그인을 서버 방식으로 바꾸기지금은 이 컴퓨터 안에서만 확인하는 방식입니다. 실제 운영에서는 서버에서 확인해야 안전합니다.
  • 자료를 서버에 저장하도록 바꾸기브라우저 저장 방식이라 컴퓨터가 바뀌면 자료가 사라집니다.
  • 도메인 확정 후 검색 설정 파일 교체검색 노출에 쓰이는 파일의 주소를 실제 도메인으로 바꿔야 합니다.
  • 이용약관·개인정보처리방침 법무 검토지금 문구는 초안입니다.

막히시면 연락 주세요

이 매뉴얼로 해결되지 않는 일은 담당자에게 문의하시면 됩니다.
연락 전에 어느 메뉴에서, 어떤 버튼을 눌렀을 때, 무엇이 나왔는지를 적어두시면 훨씬 빨리 해결됩니다.
